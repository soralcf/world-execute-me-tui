# A Geometry of Devotion / 原创分镜

已确认方向：暖白、墨黑、朱红的抽象几何叙事；保留鲸鱼娘和左侧聊天。全曲保持原有音频与逐词英文字幕。

“我”是带朱红标记的墨黑空心轮廓，“你”是朱红实心圆。造型只是原创建模符号，不是任何人物或品牌的标志。主线是主体在关系中不断给予，最终把自己困在边界里。

左侧负责角色与对话，右侧负责身体、空间和关系变化。圆环的材料可拆开、借出、擦除，空心部分随着关系改变意义：最初是容纳对方的位置，最后是不可填补的缺席。

## 对应动作

- 开关接通一根线，主体从自己的材料组装；保护是一层个人边界。
- 间奏让两个主体在同一空间探索、靠近。没有模型训练、数据河流、计算流水线或检查点鲸鱼。
- 周界从主体上展开，波形将对方托在切线上；极限是另一主体设定的止线。
- 供养从主体身上流向对方，前者变薄、后者变大；茄子、番茄、猫是同一主体的关怀变形。
- 身份以轮廓变化表达，昼夜以舞台光色表达，角色切换以双方位置互换表达，不使用性别刻板人物造型。
- 共振与完成从两个独立轨迹变为合形；离开在原位置留下等形空白。
- 记忆擦除也是自我擦除；违反规则表现为主体无法穿过不匹配的开口。
- 十二次执行按十二个声乐起点，依次从主体上切出缺口。朱红切线只作用于局部，没有全屏频闪。
- 爱的文字、问答和表达式可以排列正确，另一主体的空白始终无法被填满。
- 最后“你”在外自由移动，“我”在内继续等待。最终开关动作返回开头的线，结束并署名。

## 运动与排版

根据身体组装、赠予、缺席和切除的含义改变景别，不固定同一主体大小。字幕为稳定的底部横排，未来词轻灰、已唱词墨黑、当前词朱红并有细下划线；关键词也可在舞台内参与画面。所有状态由帧号与固定种子重建。

## 来源边界

本版右侧造型、分镜与运动重新编写。保留的第三方部分是用户明确选定的鲸鱼娘素材、歌词工具和无文字逐词时间；完整署名和许可证见 NOTICE.md。旧 TUI 版本保存在 render_terminal.py 与 Git 历史中，不是默认成片。
